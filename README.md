# Network Mode Guard

macOS 菜单栏网络模式切换器：在用户已登记的 Clash、Surge、Palantir 与直连模式之间，经过预检、确认、验证与条件化回退后安全切换。

## v0.1 目标

- 将当前网络归类为：直连、Clash 代理、Surge VPN、Palantir VPN、冲突或未知。
- 展示本次切换将关闭、启动和不触碰的网络接管层。
- 对已验证可操作的模式提供“切换前预检 → 用户确认 → 执行 → 验证 → 条件化回退”流程。
- 代理/PAC 残留仅作为模式切换中的冲突项处理，不管理客户端内部节点、订阅、规则或 DNS 配置。

本项目只在本机读取或修改网络状态，不上传订阅链接、令牌、节点地址或浏览记录。

## 当前状态

已接入只读网络采集、模式分类、模式登记和切换预检界面；系统写入执行层与第三方 VPN 控制仍需真实机验证后启用。详细范围、架构和验收标准见 [docs/mvp-plan.md](docs/mvp-plan.md)。

## 本地启动

```bash
swift run
```

当前版本可读取系统网络状态并生成切换预览；不会在未完成能力验证和用户确认前写入网络设置。

## 安全原则

- 所有网络设置写入均须在界面显示精确影响范围后由用户确认。
- 切换前保存快照；验证失败时提供回滚。
- 代理/PAC 残留仅在模式切换中、且明确属于正离开模式时才关闭；不删除第三方应用、订阅或网络扩展。
- 不把令牌、订阅 URL、配置正文或诊断原始日志写入持久化文件。
